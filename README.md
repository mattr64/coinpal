# coinpal
It's a small plugin I made to make things easier when figuring out how much stuff costs when planning a trip abroad.
It detects foreign currency strings and offers a conversion in-page by hovering the mouse.
You can differentiate behaviour with commonly used currency symbols ($, for example) by adding a site differentiator in the settings, for example 'sosimhk.com' can be forced to match $ to HKD, whereas amazon.com can be forced to match $ as USD.

You can also add new currency regexps if you so wish.
